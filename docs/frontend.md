# Интерфейс Nero

Первая реализованная часть: регистрация и вход на Go + templ + Tailwind CSS 4 + htmx 4.0.0.

## Запуск

Из корня проекта:

```sh
npm ci
npm run build:ui
make run
```

`make run` использует существующий `.env` и PostgreSQL. Окружение и миграции нужно подготовить как для обычного запуска бэкенда.

- Регистрация: http://localhost:5050/register
- Вход: http://localhost:5050/login

При разработке можно запустить `npm run css:watch` и `make dev` в двух терминалах. CSS пересобирается первым процессом, шаблоны и Go — вторым. Прокси templ сообщает свой адрес при запуске.

## Где что менять

- `internal/web/views/layout.templ`: HTML-каркас, CSS, шрифты и скрипты.
- `internal/web/views/auth.templ`: общая композиция экранов, поля, кнопки и экран подтверждения.
- `internal/web/views/register.templ` и `login.templ`: конкретные страницы и фрагменты форм.
- `internal/web/views/auth.go`: данные для отображения; пароль здесь отсутствует.
- `web/styles/input.css`: палитра, Tailwind и несколько общих CSS-компонентов.
- `web/static/js/auth.js`: показ пароля, состояние отправки и сообщение о сетевой ошибке.
- `internal/web/handlers/auth.go`: чтение HTML-форм, вызов сервиса авторизации, ошибки и переходы.
- `cmd/messenger/main.go`: подключение маршрутов и статических файлов.

`*_templ.go` генерируются командой `go tool templ generate`. `web/static/css/app.css` генерируется Tailwind. Эти файлы включены в исходники, поскольку текущий Dockerfile собирает Go без отдельного этапа сборки интерфейса. После изменения шаблонов или стилей запускай `npm run build:ui` перед сборкой контейнера.

htmx хранится локально в `web/static/js/htmx.min.js`; страницы не зависят от CDN.

## Как проходит запрос

1. `GET /register` или `GET /login` возвращает полную HTML-страницу.
2. Форма отправляет `application/x-www-form-urlencoded` на `POST /register` или `POST /login`.
3. HTML-обработчик вызывает существующий `AuthService`. Запрос к собственному JSON API не выполняется.
4. При ошибке обычная форма получает полную страницу, htmx — фрагмент `#auth-content`. Имя и username сохраняются, пароль очищается. htmx 4 отображает также HTML-ответы 401, 409 и 422.
5. При успехе сервер сохраняет токены в HttpOnly cookie и отправляет браузер на `/welcome`. Для обычной формы используется 303, для htmx — `HX-Redirect` с 204. Повторное обновление страницы не повторяет регистрацию.

`/welcome` — пока только подтверждение входа. Оно проверяет подпись и срок действия access-токена. Страница чата ещё не подключена.

## Cookie и существующий API

- `nero_access`: access-токен HTML-интерфейса, `Path=/`, срок из `AUTH_ACCESS_TOKEN_TTL`.
- `refresh_token`: существующая cookie с прежним `Path=/api/v1/auth`.
- Обе cookie HttpOnly и SameSite=Lax; Secure включён в production.
- JSON API продолжает принимать access-токен в `Authorization: Bearer`; cookie интерфейса не меняет этот контракт.
- Автоматическое обновление access-токена для HTML-страниц пока не реализовано. При его истечении `/welcome` возвращает на вход. Перед подключением чата нужно определить общий поток обновления и выхода для интерфейса.

POST-маршруты интерфейса защищены `http.CrossOriginProtection`. JSON API этим изменением не затрагивается. Формы ограничены 8 КиБ; имя, username и пароль проверяются по существующим правилам домена. Содержимое ошибок сервера и пароль не возвращаются в HTML.

## Адаптивность

Один шаблон для всех размеров: до 768 px декоративная панель скрыта, остаются логотип и форма. Поля имеют размер текста 16 px на телефоне. Ширина формы ограничена 335 px, высота страницы растёт вместе с содержимым. На больших экранах интерфейс расположен в рамке шириной 1100 px.

## Проверки

```sh
go test ./...
```

Тесты `internal/web/handlers/auth_test.go` проверяют валидацию, ошибки сервиса, обычные и htmx-ответы, безопасный вывод пользовательских значений, cookie, ограничения запроса и защиту от межсайтовой отправки формы. Для тестов используются подставные сервисы; они не записывают данные в PostgreSQL.

Официальные справочники: [templ](https://templ.guide/), [Tailwind CSS](https://tailwindcss.com/docs/), [htmx 4](https://four.htmx.org/docs), [CrossOriginProtection](https://pkg.go.dev/net/http#CrossOriginProtection).
